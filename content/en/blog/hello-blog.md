This is the first blog post for the new Hugo-powered site.

Future posts can be added as Markdown files under `content/en/blog/`. Each post uses front matter for the title, date, tags, category, description, and summary.

## What changed

- Posts are written in Markdown.
- Hugo builds the static site.
- GitHub Actions deploys it to GitHub Pages.
- Pagefind can generate a static search index after each build.
